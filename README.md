# ☕ BrewHaven — Coffee Shop Website

A modern, elegant, and fully responsive static website built for a coffee shop/café using **HTML5 and CSS3**. This project focuses on clean UI/UX design, beautiful typography, and responsive layouts.

---

## 🚀 Key Features

* **🌟 Immersive Hero Section:** Eye-catching landing banner with a welcoming tagline and Call-to-Action (CTA) buttons.
* **📋 Interactive Menu Showcase:** Categorized coffee and pastry menu with pricing cards and mouth-watering imagery.
* **📖 About Us Story:** Section highlighting the brand's origin, quality beans, and passion for coffee.
* **💬 Customer Testimonials:** Real-looking customer feedback cards to build social proof.
* **📍 Contact & Location Form:** Clean footer and contact section with operating hours and social links.
* **📱 Fully Responsive Design:** Optimized using CSS Media Queries, Flexbox, and Grid for seamless viewing on mobile phones, tablets, and desktops.

---

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic tags)
* **Styling:** CSS3 (Flexbox, Grid, Custom Variables, Animations)
* **Fonts & Icons:** Google Fonts (e.g., Poppins / Playfair Display) & FontAwesome Icons
* **Version Control:** Git & GitHub
